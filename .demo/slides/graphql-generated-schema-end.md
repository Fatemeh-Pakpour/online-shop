# Recap

- `schema.gql` is generated by NestJS GraphQL
- TypeScript decorators are the source of truth
- Change models, inputs, and resolvers
- Restart the API to regenerate the schema
- Do not manually develop generated files

Test query:

```graphql
query {
  categories {
    id
    name
  }
}
```
